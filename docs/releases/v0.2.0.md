# DSH Time Machine v0.2.0

这是 DSH Time Machine 的首个公开 GitHub Release。它是 DeepSeek Harness 的非官方社区插件；界面默认中文，可切换英文。

## 这次发布带来了什么

- 在 DSH 会话边界同时记录消息状态和工作区检查点，可以先预览，再安全回退。
- 用 DAG 保留失败探索和平行分支；回退前会建立救援检查点，避免单向覆写。
- 在命令行或独立 Web 仪表盘查看差异、恢复选定文件和检查失败证据。
- Git 工作区使用独立索引创建快照；非 Git 目录使用 manifest 与内容哈希降级。
- 恢复计划会显式展示 Agent 写入记录及已声明的外部副作用。

## 安装

需要 Node.js `^22.19.0 || >=24.0.0`、DSH `>=0.1.5-rc.2 <0.2.0` 和 `web` profile。确保 DSH 安装环境中可使用 pnpm，然后运行：

```bash
dsh plugin --profile web add github:GeoSyntax/dsh-plugin-time-machine#v0.2.0
```

安装后重启 DSH。详细步骤见[中文快速开始](https://github.com/GeoSyntax/dsh-plugin-time-machine/blob/v0.2.0/README.md)和 [English quickstart](https://github.com/GeoSyntax/dsh-plugin-time-machine/blob/v0.2.0/README.en.md)。

## 安全边界

默认安全模式会拒绝未经验证的工作区漂移。会话分支仍共享同一工作区，本版本不提供独立 worktree 或容器隔离。文件恢复不能撤销数据库事务、网络调用、进程或云端变更；恢复前请检查预览与外部副作用提示。可选的 DSH Web 客户端 companion 单独分发，不在本核心包中。

## 发布文件与验证

附件 `dsh-plugin-time-machine-0.2.0.tgz` 是 npm 格式的安装包，`SHA256SUMS.txt` 提供 SHA-256 校验值。**此次 GitHub Release 不会发布 npm 包**；npm 发布将在账户授权完成后单独执行。

[测试计划](https://github.com/GeoSyntax/dsh-plugin-time-machine/blob/v0.2.0/docs/TEST_PLAN.md)记录了 DSH 宿主及 Web 验证。仓库 CI 覆盖 Windows、macOS、Ubuntu 上的 Node.js 22/24，以及包导入、Bundle 加载、客户端 companion 和依赖审计。
